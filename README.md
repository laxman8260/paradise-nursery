# Paradise Nursery Shopping Cart Application

Paradise Nursery is a React-based e-commerce shopping cart application for houseplants.

This project allows users to:

• Browse different categories of houseplants  
• View plant name, image, and price  
• Add plants to a shopping cart  
• Increase or decrease item quantity  
• Remove items from the cart  
• View total cart cost dynamically  

Technologies used:

React  
Redux Toolkit  
JavaScript  
CSS
